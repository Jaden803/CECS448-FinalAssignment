### In order to run the application locally, follow these steps

1. Clone the repo to your local machine using the command: `git clone https://github.com/Jaden803/CECS448-FinalAssignment.git`
2. Install node.js and npm on your local machine via [their official website](https://nodejs.org/en/download)
3. Install all dependencies for the project
    - Open a powershell window in the cloned repository on you local machine
    - Run the command `npm install`
4. Host the application locally
    - Run the command `npm run dev`
    - Follow the generated link to view the application
